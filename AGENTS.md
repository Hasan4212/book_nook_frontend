## Stack

- Next.js 16.4.3, App Router only (`src/app`); React 19.3. No Pages Router.
- Import alias: `@/*` → `src/*` (`tsconfig.json`).
- Tailwind CSS v4 via `@tailwindcss/turbopack`, wired through a `turbopack.rules` entry in `next.config.ts` — there is no PostCSS config; don't add one, and don't set up Tailwind via `postcss.config.*`.

## Dev/build commands

- `npm run dev` — dev server; Next 16 uses Turbopack by default, so no launcher flags needed.
- `npm run lint` — runs bare `eslint` with no paths; flat-config ESLint 9 lints the cwd by default, so this is correct as-is. Typecheck has no dedicated script: use `npx tsc --noEmit`.
- No tests exist (no test runner installed) — verification = lint + `npx tsc --noEmit` + `npm run build`.

## Compiler/experimental behavior

`npm run dev`/`build` enable these flags in `next.config.ts`, which change how code should be written:

- `reactCompiler: true` + `babel-plugin-react-compiler` — don't add manual memoization (`useMemo`/`useCallback`/`React.memo`); the compiler handles it.
- `cacheComponents: true` — data fetching is dynamic by default; caching is opt-in via the `use cache` directive (plus `cacheLife`/`cacheTag`). Static HTML shells + streamed dynamic content is default (PPR built in). Gotchas:
  - Requires the Node.js runtime: no `runtime` route segment exports (`runtime = 'nodejs'` or `'edge'`) anywhere in route files.
  - See docs at `node_modules/next/dist/docs/01-app/03-api-reference/05-config/01-next-config-js/cacheComponents.md` before writing server data fetching.
- `partialPrefetching: true` — must be explicitly set next to `cacheComponents` (omitting it logs a warning); changes link prefetch behavior vs older Next defaults.

## Layout / fonts / theming

- `src/app/layout.tsx` loads **two** Google fonts via `next/font`: `Josefin_Sans` (`font-sans`) and `Lora` (`font-serif`), mapped to Tailwind in the `@theme inline` block of `src/app/globals.css`. New pages inherit layout styling; don't re-set fonts and don't hardcode font-family classes.
- Dark theme colors are CSS vars (`--background: #0d1a14`, `--foreground: #f4f6f5`) in `globals.css`, exposed as Tailwind tokens. Use `bg-background`/`text-foreground`, not raw hex.

## Structure / backend expectations

- Routes: `/` (`src/app/page.tsx`) and `/all-books`. Components live in `src/components/` (`Navbar`, `Banner`) and `src/components/Body/` (`NewArrivals`). `Navbar` is rendered by the root layout on every page.
- This repo is frontend-only (no backend, DB, API routes, or tests), but data pages fetch `http://localhost:8000/books` in client components with `useEffect` — a separate backend must be running on port 8000 locally or those pages show empty/error states. Use `next/image`'s allowlist in `next.config.ts` (`images.unsplash.com`, `i.pravatar.cc`) for any new remote image host.
- `next-env.d.ts` is gitignored and regenerated by `next dev`/`next build` (`tsconfig.json` include expects it; don't create or edit by hand).
- Git: `.env*`, `/.next/`, `next-env.d.ts` are untracked by design; do not commit them.
